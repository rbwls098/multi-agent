# B. 외부 MCP 서버 활용 

## 1. 비교 메모 (3~5줄)

직접 만든 날씨 서버는 처음부터 API 호출, 에러 핸들링, 입력과 출력 형식까지 꼼꼼히 구현해야 했지만, `Filesystem`과 `Fetch` 같은 외부 MCP 서버는 `.mcp.json` 파일에 커맨드 네 줄만 추가하면 즉시 강력한 파일 입출력 및 요약 도구를 내 에이전트에서 바로 호출할 수 있었습니다. 특히 서로 다른 역할을 하는 도구(`weather`로 조회 → `filesystem`으로 저장 → `fetch`로 정보 가져오기)를 한 대화에서 매끄럽게 연결해 사용하는 경험은, MCP의 가장 강력한 장점인 "잘 정의된 도구만 있다면 구현 없이 무한한 확장"이 가능하다는 점을 똑똑히 보여주었습니다.

---
*(참고: 외부 MCP 파일시스템이나 Fetch 서버를 호출하여 결괏값을 가져오는 화면 캡처 파일 2장은 이 폴더에 사용자가 직접 넣어주셔야 합니다.)*
